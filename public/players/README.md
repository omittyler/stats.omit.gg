# Player Photos

Drop player photo files here. Use a filename you then reference in `photo_filename` in `data/incoming/players.csv` — e.g. `Simp.png` referenced as `Simp.png`.

Keep filenames simple: alias only, no spaces (use `_` or `-` if needed), consistent extension casing.

**`DefaultPlayer.png`** is a fallback sentinel (same pattern as `Default.png` in `public/teams/`) — used as the photo for any player who doesn't have a real photo on file. Don't overwrite or repurpose it.
